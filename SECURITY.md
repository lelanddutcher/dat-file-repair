# Security

DATfix reads untrusted files: `.DAT` recordings, reference clips and card images. A file that
crashes DATfix, makes it read or write outside the files you chose, or makes it hang is a security
problem.

## Report a problem

Do not open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/lelanddutcher/dat-file-repair/security/advisories/new)
for this repository. Include the DATfix version, your operating system and the steps to reproduce.
If a file triggers the problem, say so; we will arrange a private way to share it.

## Supported versions

Only the latest release gets fixes.
